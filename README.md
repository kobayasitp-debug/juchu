# 受注・製品管理（iPad / PC 対応・オフライン版）

同じアプリが、iPadではタッチ向けの画面、PCでは左メニューと表形式の画面に自動で切り替わります。
設定タブの「表示モード」で、PC表示・iPad表示のどちらかに固定することもできます。

## 公開のしかた（最初の1回だけネットが必要）

このフォルダの中身をどこかのWebサーバー（HTTPS）に置きます。無料で簡単なのは GitHub Pages です。

1. GitHub に新しいリポジトリを作成（Free プランは Public のみ Pages が使えます）
2. このフォルダの中身を**すべて**アップロード（index.html, sw.js, manifest.webmanifest, アイコン3つ, **ocr2フォルダ**）
   - ocr2フォルダは写真読み取り用です。フォルダごとドラッグ＆ドロップすれば中身ごと入ります
3. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save
4. 表示された URL（https://ユーザー名.github.io/リポジトリ名/）を開く

※ データ（注文・製品・写真・図面）は各端末の中だけに保存され、サーバーには送られません。
　URL を知られても、他人に見えるのは空のアプリだけです。

## iPadで使う

1. iPad の Safari で URL を開く
2. 共有ボタン → 「ホーム画面に追加」
3. 以後はホーム画面のアイコンから起動（機内モードでも動きます）

## PCで使う（Chrome または Edge）

1. Chrome か Edge で URL を開く
2. アドレスバー右端の「インストール」アイコンをクリック
   （見当たらない場合は「︙」/「…」メニュー →「キャスト、保存、共有」または「アプリ」→「ページをアプリとしてインストール」）
3. 以後はデスクトップやスタートメニューの「受注・製品管理」から起動（オフラインでも動きます）

PC向けの操作:
- 注文書の画像を注文一覧の画面にドラッグ → 読み取って注文を登録
- 写真読み取り画面で Ctrl+V → クリップボードの画像を読み取り
- 図面・写真は各欄や製品カードにドラッグで追加
- 図面の表示：マウスホイールで拡大、ドラッグで移動、ダブルクリックで切替、←→で前後
- キーボード：N 新しい注文 / / 絞り込み・検索 / 1〜4 画面切替 / Ctrl+S 保存 / Esc 閉じる
- 設定 →「注文一覧をCSVで書き出す」で Excel で開けるファイルを保存

## iPadのデータをPCへ移す

1. iPad で設定 →「書き出す」
2. できたファイル（受注管理バックアップ_日付.json）を AirDrop・メール・iCloud Drive などで PC へ送る
3. PC で設定 →「バックアップから復元」でそのファイルを選ぶ

iPad と PC のデータは自動では同期しません。両方で入力すると内容がずれるので、ふだん使う端末を1台に決めてください。

## 弥生販売のCSVから取り込む

1. 弥生販売で受注伝票（受注台帳など）をテキストファイル（CSV）にエクスポートする
2. このアプリの注文一覧で「弥生CSV取込」を押してファイルを選ぶ（PCは注文一覧にドラッグでも可）
3. 列の割り当てと取り込み内容を確認して「取り込む」

- Shift-JIS・UTF-8、カンマ区切り・タブ区切りのどちらにも対応。見出し行があれば自動で列を判定します
- 列の割り当ては記憶され、次回から同じ形式のファイルは自動で同じ設定になります
- 型番は「規格・型番」→ 商品名の中の型番 → 商品コード の順で探し、加工区分（接着・張替・リベット）は商品名から自動で選びます
- 受注番号＋行番号で判定するので、同じファイルを何度取り込んでも二重登録されません（「更新する」にチェックすると納期・数量などを弥生の内容に更新）
- 商品コードも数量もない行（摘要だけの行）は、同じ伝票の明細の備考に入ります
- 弥生販売の「受注明細」書き出し（見出しなし・45列）は自動で形式を判定します。受注残数が0の明細は「完了」、緊急対応費などの付帯費用は同じ受注番号の明細の備考にまとめ、緊急なら「急ぎ」にします

## 写真から自動入力

- 注文書・FAX・作業票の画像から、顧客名・加工区分・型番・数量・注文日・納期・急ぎ・受注No.などを読み取ります。
- 読み取りは端末の中で行います（画像は外部に送られません）。初回起動時に約32MBの読み取り用データ（PaddleOCR）を自動で取り込み、以後はオフラインで使えます。
- 設定タブで自社名を登録すると、自社名を顧客名と取り違えにくくなります。

## 注意

- データは端末の中のみ。**設定タブの「書き出す」で定期的にバックアップ**してください。
- iPad のホーム画面アプリや PC のブラウザのサイトデータを削除すると、データも消えます。
- アプリを更新するときは、ファイルを差し替えたうえで `sw.js` の `VERSION` を変更してください。v1.6以降は、ネットにつながっていれば次の起動で自動的に最新版になります（設定タブの「最新版を確認」でも切替可）。
- 音声ボタンはネット接続が必要です。使えないときは、iPad はキーボードのマイクボタン、Windows は「Windowsキー＋H」で音声入力できます。
